# 🧶 MyPatterns

אפליקציה (PWA) לשמירה ומעקב אחרי דוגמאות סריגה. עובדת במחשב ובאנדרואיד (אפשר להתקין אותה כאפליקציה), ומסתנכרנת לתיקייה בגוגל דרייב.

## מה יש באפליקציה
- **דשבורד** עם כל התיקיות שבתיקיית הדוגמאות בדרייב. לכל תיקייה ולכל קובץ אפשר להוסיף **תמונה מייצגת** בכפתור ⋯ שעל הכרטיס (בטלפון אפשר גם לצלם). התמונות נשמרות בדרייב, בתוך התיקייה.
- פתיחה של **PDF**, **Word (docx/doc)**, מסמכי Google Docs ו**תמונות** של תרשימים.
  - בקובצי docx יש כפתור **"תצוגה מדויקת"**: הקובץ מומר דרך גוגל ל-PDF, כך שהעימוד נשמר בדיוק כמו בוורד. קובצי doc ישנים מומרים כך באופן אוטומטי.
- **סרגל אופקי וסרגל אנכי** בצבע שקוף:
  - גוררים את הסרגל באצבע או בעכבר. הדוגמה עצמה לא זזה.
  - 🎨: שליטה בעובי של כל סרגל, בצבע ובשקיפות, ואפשרות להאפיל את שאר הדף.
  - ▲▼ ◀▶: הזזת הסרגל בצעד אחד בגובה הסרגל, כלומר שורה אחת. במחשב אפשר להשתמש גם בחיצי המקלדת.
  - "נעילת הדוגמה": הדף לא יגלול בטעות.
- **מונה שורות**: ‎+ / −‎, ולחיצה על המספר מאפשרת לקבוע אותו. במחשב אפשר להשתמש גם במקשים ‎+ / −‎.
- **שמירת התקדמות**: מיקום הסרגלים, העובי, הזום, הגלילה ומונה השורות נשמרים לכל קובץ **בדרייב עצמו**. אם מתחילים לסרוג במחשב, ממשיכים בטלפון מאותה נקודה.
- זום: צביטה בטלפון, Ctrl+גלגלת במחשב או הכפתורים.
- **בלי אינטרנט**: קבצים שכבר נפתחו נשמרים במכשיר, ואפשר לפתוח אותם גם בלי חיבור.
- העלאת דוגמאות חדשות ויצירת תיקיות ישירות מהאפליקציה (כפתור ＋).

## הגדרה חד-פעמית

### 1. אחסון האתר
לאפליקציה צריך להיות כתובת https. האפשרות הכי פשוטה והחינמית היא **GitHub Pages**:
1. ליצור מאגר (repository) חדש ב-GitHub ולהעלות אליו את כל הקבצים שבתיקייה הזו.
2. במאגר: Settings ← Pages ← Source: `Deploy from a branch`, ולבחור ב-`main` / `root`.
3. אחרי כדקה האפליקציה תהיה זמינה בכתובת כמו `https://USERNAME.github.io/MyPatterns/`.

(אפשר גם Netlify או Cloudflare Pages: פשוט גוררים את התיקייה לאתר שלהם.)

### 2. יצירת Client ID בגוגל (כ-5 דקות)
1. להיכנס ל-https://console.cloud.google.com וליצור פרויקט חדש (למשל "Knitting").
2. **APIs & Services ← Library**: לחפש **Google Drive API** וללחוץ **Enable**.
3. **APIs & Services ← OAuth consent screen**, או **Google Auth Platform** בממשק החדש:
   - User type: **External**. ממלאים שם אפליקציה ואימייל.
   - בחלק **Audience / Test users** מוסיפים את כתובת הג'ימייל שלך.
   - אפשר להשאיר את האפליקציה במצב **Testing**, והיא תעבוד לחשבונות שהוספת.
4. **Credentials ← Create credentials ← OAuth client ID**:
   - Application type: **Web application**
   - **Authorized JavaScript origins**: מוסיפים את כתובת האתר **בלי נתיב**, למשל `https://USERNAME.github.io`.
   - לוחצים Create ומעתיקים את ה-**Client ID**. הוא מסתיים ב-`apps.googleusercontent.com`.
5. פותחים את האפליקציה, מדביקים את ה-Client ID ומתחברים.
   אפשר גם להדביק אותו מראש בקובץ `config.js`, וכך לא צריך להזין אותו בכל מכשיר.

> בהתחברות הראשונה גוגל תציג אזהרה ש"האפליקציה לא אומתה". זה תקין לאפליקציה פרטית: לוחצים **Advanced ← Go to … (unsafe)**.

### 3. בחירת התיקייה
אחרי ההתחברות נפתח דפדפן תיקיות. מנווטים לתיקיית הדוגמאות ולוחצים **"בחירת התיקייה הנוכחית"**. כל תת-תיקייה תופיע בדשבורד ככרטיס.
אפשר להחליף את התיקייה בכל זמן דרך ⚙ הגדרות.

## התקנה באנדרואיד
פותחים את הכתובת ב-**Chrome** ← תפריט ⋮ ← **"התקנת אפליקציה"** או **"הוספה למסך הבית"**. האפליקציה תיפתח במסך מלא, כמו אפליקציה רגילה.
במחשב: ב-Chrome או ב-Edge יש אייקון התקנה בשורת הכתובת.

> רוצים קובץ APK אמיתי לחנות Play? אפשר להכניס את כתובת האתר ל-https://www.pwabuilder.com ולהוריד חבילת אנדרואיד.

## איפה נשמר המידע
| מה | איפה |
|---|---|
| הדוגמאות | בדרייב, בתיקייה שבחרת |
| תמונות מייצגות | בדרייב, בתוך התיקייה, בשם `_תמונה_…jpg` |
| התקדמות (סרגלים, מונה, זום) | בדרייב, כמאפיינים נסתרים (appProperties) של הקובץ |
| צבעי הסרגלים ועותק לעבודה בלי אינטרנט | במכשיר |

## מבנה הקבצים
```
index.html            מבנה המסכים
styles.css            עיצוב
app.js                כל הלוגיקה (דרייב, דשבורד, מציג, סרגלים)
config.js             מקום להדבקת ה-Client ID (לא חובה)
sw.js                 עבודה בלי אינטרנט
manifest.webmanifest  התקנה כאפליקציה
vendor/               pdf.js (תצוגת PDF) ו-mammoth (תצוגת Word)
icons/                אייקונים
```
