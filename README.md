# 🧶 MyPatterns

אפליקציה (PWA) לשמירה ומעקב אחרי דוגמאות סריגה. עובדת במחשב ובאנדרואיד (אפשר להתקין אותה כאפליקציה), ומסתנכרנת לתיקייה בגוגל דרייב.

## מה יש באפליקציה
- **דשבורד** עם כל התיקיות שבתיקיית הדוגמאות בדרייב. לכל תיקייה ולכל קובץ אפשר להוסיף **תמונה מייצגת** בכפתור ⋯ שעל הכרטיס (בטלפון אפשר גם לצלם). התמונות נשמרות בדרייב, בתוך התיקייה.
- פתיחה של **PDF**, **Word (docx/doc)**, מסמכי Google Docs ו**תמונות** של תרשימים.
  - בקובצי docx יש כפתור **"תצוגה מדויקת"**: הקובץ מומר דרך גוגל ל-PDF, כך שהעימוד נשמר בדיוק כמו בוורד. קובצי doc ישנים מומרים כך באופן אוטומטי.
- **סרגל אופקי וסרגל אנכי** בצבע שקוף:
  - גוררים את הסרגל באצבע או בעכבר. הדוגמה עצמה לא זזה.
  - 🎨: שליטה בעובי של כל סרגל, בצבע ובשקיפות, ואפשרות להאפיל את שאר הדף.
  - ▲▼ ◀▶: הזזת הסרגל בצעד אחד בגובה הסרגל, כלומר שורה אחת. במחשב אפשר להשתמש גם בחיצי המקלדת.
  - "נעילת הדוגמה": הדף לא יגלול בטעות.
- **מונה שורות**: ‎+ / −‎, ולחיצה על המספר מאפשרת לקבוע אותו. במחשב אפשר להשתמש גם במקשים ‎+ / −‎.
- **שמירת התקדמות**: מיקום הסרגלים, העובי, הזום, הגלילה ומונה השורות נשמרים לכל קובץ **בדרייב עצמו**. אם מתחילים לסרוג במחשב, ממשיכים בטלפון מאותה נקודה.
- זום: צביטה בטלפון, Ctrl+גלגלת במחשב או הכפתורים.
- **בלי אינטרנט**: קבצים שכבר נפתחו נשמרים במכשיר, ואפשר לפתוח אותם גם בלי חיבור.
- **כפתור ＋ אחד לכל דרכי ההוספה:** קובץ מהמכשיר (PDF / Word / Excel), תמונה או צילום, מגוגל דרייב, מעננים אחרים (Dropbox / OneDrive / iCloud דרך בורר הקבצים של הטלפון), קישור מהאינטרנט, חיפוש דוגמה ברשת, ותיקייה חדשה.
- **שפות:** עברית (ברירת מחדל), English, Русский, العربية, Deutsch, Español, Italiano, Français – בוחרים ב-⚙ הגדרות.
- **גיליונות:** Google Sheets ו-Excel מוצגים אחרי המרה ל-PDF דרך גוגל.
- **קישורים לדוגמאות מהאינטרנט:** ＋ ← "הוספת קישור". הדף נפתח בתוך האפליקציה עם הסרגלים (אם האתר מאפשר), ותמיד אפשר לפתוח בדפדפן. בטלפון (אחרי התקנה) אפשר לשתף קישור מהדפדפן ישירות ל-MyPatterns.
- **חיפוש דוגמה לפי תמונה:** ＋ ← "חיפוש דוגמה לפי תמונה" – Google Lens, או חיפוש במילים ב-Google, Ravelry, Pinterest ו-Etsy (חינמיות ובתשלום).

## הרשאות: מה האפליקציה רואה בדרייב
האפליקציה משתמשת בהרשאה המצומצמת **drive.file**. היא רואה **רק**:
- את התיקייה שנבחרה בבורר הקבצים של גוגל,
- קבצים ותיקיות שנבחרו בבורר ("🔓 בחירת קבצים ותיקיות מהדרייב"),
- קבצים ותיקיות שנוצרו או הועלו דרך האפליקציה עצמה.

שאר הדרייב לא נגיש לה בכלל. אם בתיקייה יש דוגמאות שלא מופיעות, לוחצים ＋ ← "בחירת קבצים ותיקיות קיימים מהדרייב" ומסמנים אותן. זה צריך לקרות רק פעם אחת לכל קובץ.

## הגדרה חד-פעמית

### 1. אחסון האתר
GitHub Pages: מאגר `MyPatterns` ← Settings ← Pages ← Source: `Deploy from a branch`, ולבחור ב-`main` / `/ (root)`.
הכתובת תהיה `https://dikla-cloud.github.io/MyPatterns/`.

### 2. הגדרה ב-Google Cloud (כ-10 דקות)
1. **פרויקט:** https://console.cloud.google.com ← בורר הפרויקטים ← **New Project** ← שם `MyPatterns` ← **Create**. מוודאים שהפרויקט נבחר.
2. **הפעלת שני APIs:** בחיפוש העליון מחפשים ולוחצים **Enable** על:
   - **Google Drive API**
   - **Google Picker API**
3. **מסך הסכמה:** מחפשים **Google Auth Platform** (או OAuth consent screen) ← **Get started**:
   - App name: `MyPatterns`, אימייל תמיכה ← Next ← Audience: **External** ← Next ← אימייל ← מסכימים ← **Create**.
   - **Audience** ← **Test users** ← **Add users** ← הג'ימייל שלך ← Save.
   - **Data Access** ← **Add or remove scopes** ← מסמנים את `.../auth/drive.file` ← Update ← Save.
4. **Client ID:** **Clients** ← **Create client** ← Web application ← שם `MyPatterns web`.
   - **Authorized JavaScript origins** ← Add URI ← `https://dikla-cloud.github.io` (בלי נתיב ובלי `/` בסוף).
   - Create ← מעתיקים את ה-**Client ID**.
5. **מפתח API:** מחפשים **Credentials** ← **Create credentials** ← **API key** ← מעתיקים (מתחיל ב-`AIza`).
   - מומלץ ללחוץ על המפתח ← **Application restrictions: Websites** ← מוסיפים `https://dikla-cloud.github.io/*`.
   - **API restrictions: Restrict key** ← מסמנים **Google Picker API** ← Save.
6. פותחים את האפליקציה, מדביקים Client ID ו-API key ← מתחברים ← בוחרים תיקייה.
   אפשר גם לכתוב את שניהם ב-`config.js`, וכך לא צריך להזין אותם בכל מכשיר. שני המזהים אינם סודיים.

> בהתחברות תופיע האזהרה "Google hasn't verified this app". זה תקין לאפליקציה פרטית: **Advanced ← Go to MyPatterns (unsafe)**.

### שיתוף עם אחרים
כל מי שמשתמש מתחבר לחשבון הגוגל **שלו** ובוחר תיקייה בדרייב **שלו**. אף אחד לא רואה את הדוגמאות של מישהו אחר.
- **עד 100 משתמשים:** מוסיפים אותם כ-Test users.
- **לכולם:** ב-Google Auth Platform ← Audience ← **Publish app**, ואז מגישים לאימות. בהרשאה drive.file מדובר באימות בסיסי (מדיניות פרטיות, דף בית, אימות דומיין) בלי בדיקת אבטחה בתשלום.

## התקנה בטלפון ובמחשב
באפליקציה יש כפתור **📲** בסרגל העליון (וגם ב-⚙ הגדרות). באנדרואיד ובמחשב (Chrome / Edge) הוא מתקין בלחיצה; באייפון הוא מציג את ההוראות ל-Safari: שיתוף ← "הוספה למסך הבית".

### אנדרואיד – ידנית
פותחים את הכתובת ב-**Chrome** ← תפריט ⋮ ← **"התקנת אפליקציה"** או **"הוספה למסך הבית"**. האפליקציה תיפתח במסך מלא, כמו אפליקציה רגילה.
במחשב: ב-Chrome או ב-Edge יש אייקון התקנה בשורת הכתובת.

> רוצים קובץ APK אמיתי לחנות Play? אפשר להכניס את כתובת האתר ל-https://www.pwabuilder.com ולהוריד חבילת אנדרואיד.

## איפה נשמר המידע
| מה | איפה |
|---|---|
| הדוגמאות | בדרייב, בתיקייה שבחרת |
| תמונות מייצגות | בדרייב, בתוך התיקייה, בשם `_תמונה_…jpg` |
| התקדמות (סרגלים, מונה, זום) | בדרייב, כמאפיינים נסתרים (appProperties) של הקובץ |
| צבעי הסרגלים ועותק לעבודה בלי אינטרנט | במכשיר |

## מבנה הקבצים

index.html            מבנה המסכים
styles.css            עיצוב
app.js                כל הלוגיקה (דרייב, דשבורד, מציג, סרגלים)
